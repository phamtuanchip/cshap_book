# Chương 10 — Code mẫu: An toàn, chi phí và quan sát

Yêu cầu: .NET SDK 10. Chạy trong thư mục này:

```
dotnet run
```

Mở địa chỉ hiển thị trong terminal (thường `http://localhost:5xxx`) bằng trình duyệt hoặc `curl`. Không cần khoá API (mọi client là bản giả). Log console có thể in xen kẽ với Console.WriteLine do bộ đệm khác nhau - đây là hiện tượng bình thường của logger bất đồng bộ, không phải lỗi.
