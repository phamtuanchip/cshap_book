# Chương 5 — Code mẫu: Tool calling

Yêu cầu: .NET SDK 10. Chạy trong thư mục này:

```
dotnet run
```

Mở địa chỉ hiển thị trong terminal (thường `http://localhost:5xxx`) bằng trình duyệt hoặc `curl`. Không cần khoá API (mô hình giả). Nếu `dotnet run` bị chính sách hệ điều hành chặn tệp .exe, chạy `dotnet bin/Debug/net10.0/ch05-tool-calling.dll` sau khi `dotnet build`.
