# Chương 9 — Code mẫu: Xử lý lỗi, versioning, OpenAPI

Yêu cầu: .NET SDK 10. Chạy trong thư mục này:

```
dotnet run
```

Mở địa chỉ hiển thị trong terminal (thường `http://localhost:5xxx`) bằng trình duyệt hoặc `curl`. Thử `/loi/khong-tim-thay`, `/api/v1/san-pham/1`, `/api/v2/san-pham/1`, `/health`, và giao diện `/scalar/v1` (môi trường Development).
