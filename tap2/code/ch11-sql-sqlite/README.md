# Chương 11 — Code mẫu: SQL cơ bản và SQLite

Yêu cầu: .NET SDK 10. Chạy trong thư mục này:

```
dotnet run
```

Mở địa chỉ hiển thị trong terminal (thường `http://localhost:5xxx`) bằng trình duyệt hoặc `curl`. (Ứng dụng console: chỉ cần chạy, không mở web.) `schema.sql` dùng được trong mọi công cụ SQLite.
